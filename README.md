# price-monitor-bot

Исходники Telegram-бота для работы с прайсом и историей цен на маркетплейсах. В [handlers.py](handlers.py) есть меню, обработчики загрузки прайса и настройки порога прибыли. В [database.py](database.py) описано хранение товаров, истории цен и уведомлений в SQLite.

Парсеры [Ozon](parsers/ozon.py), [Wildberries](parsers/wildberries.py) и [Яндекс Маркета](parsers/yandex.py), цикл [мониторинга](monitor.py) и [сопоставление с прайсом через Anthropic](ai_analyzer.py) оставлены заглушками.

## Запуск

В [main.py](main.py) есть точка входа, но импорт обработчиков требует модуля `price_parser`, которого в репозитории нет. Для запуска мониторинга, кроме этого модуля, нужны реализации парсеров и цикла проверки цен.
